# Your sites, for every project, on top of the plumbing's own (Claude, VS Code).
# One domain per line; a domain includes its subdomains:
# "github.com" also allows "api.github.com". Lines starting with # are comments.
#
# Edit with `mirabelle site add|rm <domain>`, or by hand.
# A project can have more: projects/<name>/sites.txt (`site add -n <project>`).
# After a change, `mirabelle lock` applies it to a running container.
